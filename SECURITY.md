# Security Policy

MezoBribe is an experimental testnet project. Its contracts have not been audited and must not be treated as safe for production funds.

## Supported versions

Only the current `main` branch is supported for security fixes. No production release is currently supported.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in a public issue or pull request. If GitHub private vulnerability reporting is enabled for this repository, use it to send a private report. Otherwise, contact the repository owner, [@IdcuqS07](https://github.com/IdcuqS07), through a private channel before public disclosure.

Include the affected commit or component, impact, and steps to reproduce. Redact wallet seeds, private keys, API tokens, and user data from reports, logs, and screenshots.
